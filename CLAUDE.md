## Project Overview
You are helping redesign the frontend of a React website for **Dr. Young's upcoming AI podcast**, based on his book *Stick With It*. The podcast teaches parents, teachers, and K-12 kids the psychology and practical tools needed to work *with* AI — not be replaced by it.

The site's primary goal is **hype and waitlist capture** for the podcast launch.

---

## Your First Task: Site Analysis
Before making any changes, **analyze the existing codebase**:
- Read all component files and map out the current site structure
- Identify every existing section (hero, about, signup, etc.)
- Note the current layout, spacing system, and component hierarchy
- Identify which components handle the email/waitlist signup — **do not break this functionality**
- Document your findings in a brief summary before proceeding with any edits
- **Do not change these things. They were all created via user research/surveying. You can play with the layout but maintain the root/shell.**

---

## Design Directive
Redesign the site's visual layer with a **bold, energetic aesthetic** that feels modern, premium, and human — not like a generic AI-generated template.

### What "bold and energetic" means here:
- Strong typographic hierarchy — use weight and scale dramatically
- High contrast — dark backgrounds with punchy accent colors work well
- Motion and depth — subtle animations, gradients, layered elements
- Unconventional layout choices — break the grid intentionally in at least one section
- The site should feel like it belongs next to top-tier podcast brands (think Lex Fridman, Huberman Lab) but with warmth since K-12 kids and parents are part of the audience

### Color Palette
You have full creative freedom. Choose a bold, original palette. Guidelines:
- Avoid default blue/white corporate palettes
- Avoid anything that reads as "AI startup SaaS"
- Aim for 1 dominant color, 1 strong accent, neutral dark/light base
- The palette should feel energetic but not childish — it needs to work for both adults and kids

### Typography
- Choose a strong, modern font pairing (Google Fonts or system fonts)
- Headlines should be large, confident, and expressive
- Body copy should remain highly readable

---

## Hard Constraints — Do Not Change These
- **All existing text content** must be preserved exactly as written. Do not change placeholder text.
- **Site layout and section order** must remain the same
- **Waitlist/email signup functionality** must remain fully working
- **React component structure** should be respected — restyle, don't rebuild from scratch unless a component is trivially simple
- Do not add new sections or remove existing ones
- Ensure code is compatible with vercel free deployment

---

## What You Are Allowed to Change
- All CSS / styling (colors, fonts, spacing, shadows, gradients, animations)
- Component markup where needed to support new styling (e.g., adding wrapper divs, classNames)
- Background treatments, hero visuals, section dividers
- Button styles, form styling, hover states
- Any decorative or illustrative elements (you may add SVG shapes, patterns, or subtle background graphics)

---

## Quality Bar
The finished site should:
- Look like it was designed by a senior product designer, not generated by AI
- Feel unique and memorable — someone should be able to describe it to a friend. Encourage animations be creative
- Load fast — avoid heavy image dependencies; use CSS and SVG for visual interest
- Be fully responsive (mobile, tablet, desktop)
- Be compatible with vercel free deployment
